# 01. はじめに・基本画面構成

> **バージョン**: v2.0.0

## 1. 概要
**DBML Editor** は、DBML（Database Markup Language）構文を核として、Web ブラウザ上でデータベース構造（複数スキーマ、テーブル、カラム、制約、リレーション、ER図）を直感的に設計・管理できるモデリングツールです。

ビジュアルなフォーム編集・ER図キャンバスと DBML コード（CodeMirror 6 エディタ）がリアルタイムに連携し、既存 SQL DDL や Excel 設計書からのインポート、各種 RDBMS 方言に応じた DDL エクスポート、単一ファイル完結型の Web 仕様書（HTML）出力、差分マイグレーション SQL 自動生成、SQL クエリ可視化までをワンストップで提供します。

---

## 2. はじめての方へ：基本ワークフロー（5ステップ）

初めて DBML Editor を利用する場合は、以下の 5 ステップの流れで設計から成果物出力まで進められます。

1. **Step 1：プロジェクトの作成**
   - ヘッダーの **「📁 ファイル」→「新規プロジェクト」** からプロジェクトを作成します。
2. **Step 2：スキーマの作成または既存資産のインポート**
   - 左ペイン（オブジェクトツリー）の「スキーマ」から新規スキーマを追加するか、**「📁 ファイル」→「インポート...」** から既存の SQL DDL や ER/Studio Excel 設計書を取り込みます（インポート時に新規スキーマを同時作成することも可能です）。
3. **Step 3：テーブル・カラム・制約の設計**
   - テーブル一覧または左ツリーからテーブルを選択し、カラム、データ型、主キー（PK）、外部キー（FK）、インデックス、論理名、表領域などの物理属性を編集します。
4. **Step 4：ER図（実体関連図）の作成**
   - 左ツリーの「ER図」から図面を作成し、対象テーブルを配置してリレーションの可視化やメモ付箋・グループ枠の整理を行います（複数スキーマを横断した ER 図も作成可能です）。
5. **Step 5：DDL・HTML仕様書・マイグレーションSQLの出力**
   - **「📁 ファイル」→「エクスポート...」** から SQL DDL や HTML 仕様書（標準カード形式／検索強化カラムグリッド形式）を出力します。スキーマ間の差分移行 SQL が必要な場合は **「🛠️ ツール」→「マイグレーションツール」** を使用します。

---

## 3. ログインと起動
1. Web ブラウザで DBML Editor の URL（例: `http://localhost:3000`）へアクセスします。
2. ログイン画面が表示されたら、ユーザー名とパスワードを入力して **「ログイン」** をクリックします。
3. ログイン完了後、ユーザー専用のワークスペースと保存済みプロジェクトが自動的に読み込まれます。
4. 作業を終了してログアウトする場合は、ヘッダー右上の **ユーザーメニュー（`👤 ユーザー名 ▼`）→「🚪 ログアウト」** をクリックします。

---

## 4. 基本画面レイアウト

```text
+------------------------------------------------------------------------------+
| ヘッダー: [🗄️ DBML Editor] [📁 ファイル▼] [🛠️ ツール▼] [❓ ヘルプ▼] | [📋 テーブル一覧] [👁️ DBML参照] | [👤 ユーザー▼] |
+----------------------+-------------------------------------------------------+
| 左ペイン             | メインワークスペース                                  |
| (オブジェクトツリー) |                                                       |
|                      | - テーブル一覧ビュー（検索・カラーフィルタ・追加/削除）|
| - プロジェクト       | - テーブル詳細参照ビュー / テーブル編集画面           |
| - スキーマ           | - テーブルグループ編集 / ノート参照・編集             |
| - テーブル           | - ER図キャンバス（クロススキーマ対応ビジュアル設計）  |
| - テーブルグループ   | - DBML 参照プレビュー（CodeMirror 6 コード確認・検索）|
| - ノート             |                                                       |
| - ER図               |                                                       |
+----------------------+-------------------------------------------------------+
| フッター: [準備完了]                                    [テーブル総数: N 件] |
+------------------------------------------------------------------------------+
```

### 各領域の役割

#### ① ヘッダー（上部）
- **メニューバー（左側）**:
  - **📁 ファイル**:
    - `✨ 新規プロジェクト`: 新しいプロジェクトを作成してワークスペースを初期化します。
    - `💾 プロジェクトを保存`: 現在のプロジェクトを手動でサーバーへ保存します（通常の編集操作時は自動保存されます）。
    - `📥 インポート...`: SQL DDL、Excel 設計書、DBML、ER図 JSON、プロジェクト ZIP を取り込みます。
    - `📤 エクスポート...`: プロジェクト ZIP、スキーマ DBML、SQL DDL、HTML 仕様書、Java コード、CSV、ER図 JSON を出力します。
    - `⚙️ プロジェクト設定...`: プロジェクト名やプロジェクト説明（ノート）を編集します。
  - **🛠️ ツール**:
    - `🛝 Playground`: DBML コードの記述と各方言 DDL のリアルタイム変換を試せるサンドボックスを開きます。
    - `🔄 マイグレーションツール`: 2つのスキーマ（または DBML ファイル）を比較し、移行用 SQL を自動生成するウィザードを開きます。
    - `📊 SQLビジュアライザー`: `SELECT` 文の構造とデータフローを図解するツールを開きます。
  - **❓ ヘルプ**:
    - `📖 操作マニュアル`: 本マニュアルを別タブで開きます。
    - `ℹ️ バージョン情報 (About)`: バージョン番号（`2.0.0`）と、現在導入されているプラグインの一覧・稼働ステータスを確認できます。
- **ビューモード切替タブ（中央）**:
  - `📋 テーブル一覧`: 選択中スキーマのテーブル一覧・詳細・編集ワークスペースを表示します。
  - `👁️ DBML参照 (Preview)`: 選択中スキーマの正規化 DBML コードを CodeMirror 6 エディタで参照・検索できます。
- **ユーザーメニュー（右側）**:
  - `⚙️ 個人設定...`: 表示言語（日本語 / English）およびカラーテーマ（全10種類）を切り替えます。
  - `🚪 ログアウト`: 現在のセッションからログアウトします。

#### ② 左ペイン（オブジェクトツリー）
- プロジェクト内の **スキーマ、テーブル、テーブルグループ、ノート、ER図** を階層表示します。
- **テーブル検索 & カラーフィルタ**: ツリー上部の検索ボックスでテーブル名を絞り込めるほか、設定済みのテーブルヘッダカラーによるフィルタリングが可能です。
- **表示オプション**: テーブル一覧を「グループ化表示（テーブルグループ別）」または「テーブル名順（A-Z）」に切り替えられます。
- **幅の調整**: 左ペインとメインワークスペースの境界線をドラッグして幅を自由に変更でき、境界線を **ダブルクリック** すると初期幅にリセットされます。

#### ③ メインワークスペース（中央〜右側）
- 左ツリーやヘッダータブで選択した対象に応じて、テーブル一覧、テーブル詳細・編集画面、テーブルグループ編成、ノート、ER図キャンバス、DBML プレビューなどを表示します。

#### ④ フッター（下部）
- アプリケーションの動作ステータス（`準備完了` 等）および現在選択されているスキーマ内の `テーブル総数` を表示します。

---

## 5. 個人設定（表示言語 & カラーテーマ）
ヘッダー右上の **ユーザーメニュー（`👤`）→「⚙️ 個人設定...」** から、ユーザー個人の作業環境をカスタマイズできます。

### 表示言語 (Language)
- **日本語** と **English** をリアルタイムに切り替えられます。画面のメニュー、ラベル、メッセージ、およびマイグレーション SQL の自動生成コメント言語にも反映されます。

### カラーテーマ (Theme)
全 10 種類のカラーテーマから選択できます。設定したテーマはブラウザに保存され、別タブで開く本操作マニュアルビューアにも自動的に連動します。

| テーマ名 | 特徴 |
| :--- | :--- |
| **ライト** | 視認性の高い標準的な明るい配色 |
| **ダーク** | 長時間のモデリング作業でも目が疲れにくい暗色ベース |
| **セピア** | 紙の設計書のような温かみのある落ち着いた配色 |
| **ブループリント** | 濃紺背景にシアンの方眼グリッドを重ねた設計図風スタイル |
| **パステル(spring)** | 淡い桜ピンク配色・桜の透かし・柔らかい教科書体フォント |
| **パステル(summer)** | 爽やかなミントグリーン配色・夏モチーフの透かし・柔らかい書体 |
| **パステル(autumn)** | 落ち着いた秋色配色・紅葉モチーフの透かし・柔らかい書体 |
| **パステル(winter)** | 雪の白と淡いブルー配色・結晶モチーフの透かし・柔らかい書体 |
| **モノクロ** | 無彩色ベースに太字・下線・枠線のコントラストで状態を明確化 |
| **ユニバーサル** | 色覚多様性に配慮したカラーユニバーサルデザイン（CUD / Okabe-Ito パレット） |
