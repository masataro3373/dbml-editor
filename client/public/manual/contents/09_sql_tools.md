# 09. SQLツール（Playground & ビジュアライザ）

DBML Editor には、設計中のスキーマに影響を与えずに DBML と SQL DDL の相互変換を試せる **Playground** と、複雑な `SELECT` クエリの構造を図解する **SQLビジュアライザー** の 2 つの専用ツールが搭載されています。

---

## 1. Playground（DBML & DDL サンドボックス）

ヘッダーの **「🛠️ ツール」→「🛝 Playground」** から起動します。

### 主な特徴と使い方
- **DBML ライブコーディング（左ペイン）**:
  - CodeMirror 6 エディタ上で DBML コードを直接記述・編集できます。
  - 現在作業中のスキーマとは独立したサンドボックス空間のため、保存データを壊す心配なく新しいテーブル構造や構文を自由に試せます。
  - `Ctrl + F` によるテキスト検索・ハイライト移動に対応しています。
- **方言別 SQL DDL リアルタイム生成（右ペイン）**:
  - 左ペインで編集した DBML から、選択した DBMS 方言（Oracle、PostgreSQL、MySQL、SQL Server、Cloud Spanner 等）の SQL DDL が即座に生成・プレビュー表示されます。
  - 構文エラーがある場合は、エラー行番号と診断メッセージが分かりやすく表示されます。
- **コピー & クリア**:
  - 試作した DBML コードや生成された DDL をワンクリックでクリップボードへコピーして実務に活用できます。

---

## 2. SQLビジュアライザー（クエリ構造・データフロー可視化）

ヘッダーの **「🛠️ ツール」→「📊 SQLビジュアライザー」** から起動します。

複数テーブルの `JOIN`、サブクエリ、共通テーブル式（`WITH` / CTE）、集約（`GROUP BY` / `HAVING`）、フィルタ（`WHERE`）、並び替え（`ORDER BY`）などが絡み合う複雑な `SELECT` 文を解析し、**「どのテーブルからデータが取得され、どの条件で結合・絞り込み・集計されて最終出力に至るか」** を視覚的なフローグラフで図解します。

### 主な機能
1. **プロジェクト連動のインテリジェント SQL 入力補完**:
   - SQL エディタ上でクエリを記述する際、現在プロジェクト内に読み込まれているスキーマ・テーブル・カラム定義と自動的に連携します。
   - `FROM` 句や `JOIN` 句で指定した **テーブル名** や **テーブルエイリアス名（例: `FROM MST_USERS u` の `u.`）**、または **スキーマ名（`schema.`）** に続けてドット（`.`）を入力すると、該当テーブルのカラム候補一覧（物理名・論理名・データ型）がポップアップ表示され、素早く正確に入力補完できます。
2. **サンプル SQL のワンクリック読込**:
   - ツールバーのサンプル選択から、代表的な結合クエリや集計クエリのサンプルを読み込んで即座に可視化動作を確認できます。
3. **実行フローグラフ（キャンバス）**:
   - `テーブルソース` ➔ `JOIN（結合）` ➔ `WHERE（抽出条件）` ➔ `GROUP BY / HAVING（集計）` ➔ `SELECT（射影・出力カラム）` ➔ `ORDER BY / LIMIT` の各ステップがカードノードと接続線（ベジェ曲線）で自動配置されます。
   - 各ノードはキャンバス上で自由にドラッグ移動でき、左右の配置を入れ替えても接続線が自動的に最短の対向エッジへ追従します。
4. **ノード詳細インスペクタ**:
   - グラフ上の任意のノードをクリックすると、結合キー、フィルタ条件式、選択カラムとエイリアスなどの詳細情報がインスペクタに表示されます。
