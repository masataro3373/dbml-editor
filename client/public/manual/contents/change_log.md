# 11. 変更履歴 (Change Log)

## [v2.0.0] - 2026-11-25
DBML Editor v2.0.0 における主な新機能・アーキテクチャ刷新および改善点です。

### 🚀 新機能・アーキテクチャ刷新
- **プラグインアーキテクチャの導入 (`plugins/`)**:
  - 論理名拡張、RDBMS 方言（DDL生成・解析・マイグレーションSQL生成）、ER/Studio Excel インポートなどの機能をコアから分離し、ZIP パッケージとして動的に着脱可能なプラグイン基盤を構築。
  - **標準・実機検証済み公式プラグイン（7種）**: `logicalname`, `erstudio-excel`, `oracle-dialect`, `postgres-dialect`, `mysql-dialect`, `mssql-dialect`, `spanner-dialect`
  - **Beta 版公式プラグイン（4種）**: `snowflake-dialect`, `bigquery-dialect`, `redshift-dialect`, `databricks-dialect`
- **`@dbml/core` v13.0.0 へのアップデートと `logicalName` インライン属性化**:
  - DBML パーサーエンジンを最新の `@dbml/core` v13.0.0（`@dbml/parse` v13.0.0）へ更新。
  - `logicalName` を `Table` および `Column` のインラインカスタムプロパティ（`[logicalName: '...']`）へ出力し、表領域等の物理属性を `Metadata Table` ブロックへ出力するよう標準化（旧形式の読み込み互換維持）。
- **HTML 仕様書の2形式対応（標準カード形式 / 検索強化カラムグリッド形式）と日英リアルタイム切替**:
  - 従来の「標準版（テーブルカード形式）」に加え、全テーブル・全カラムを横断検索・フィルタリングできる「検索強化版（カラムグリッド形式）」を新設。
  - 出力された単一 HTML ファイル内に日本語・英語辞書を埋め込み、仕様書閲覧画面右上のボタンで **日本語 / 英語（JA / EN）をリアルタイムに切り替えられる機能** を追加。
- **スキーマ・ER図単位の `dirty` 検知による高速自動差分保存**:
  - 複数スキーマ・複数ER図を持つ大規模プロジェクトにおいて、変更が発生したスキーマおよびER図ファイルのみをサーバーへ差分送信・保存する機構を導入。
- **インポート時の新規スキーマ同時作成 & 正規化DBML出力の完全統一**:
  - インポートモーダル上で「＋新規スキーマを作成してインポート」を選択可能にし、インポート完了時点から `generateDbml()` による正規化 DBML で保存するよう統一。テーブル削除・編集後とのフォーマット差異およびマイグレーション比較時の誤差分を完全に解消。
- **Oracle DDL インポートおよびマイグレーション精度の強化**:
  - `COMPUTE STATISTICS` や `USING INDEX "IDX_NAME" ENABLE` 等の物理句を含む DDL の確実な主キー取り込み、PK と重複する `CREATE UNIQUE INDEX` の自動整理、単一・複合 PK カラムへの `NOT NULL` 自動補完を実装。
- **テーブルヘッダカラー＆カラーフィルタ機能**:
  - テーブル単位のヘッダカラー設定、プリセットカラーパレット、ERD キャンバス・PNG/SVG 出力でのカラー表示（スキーマ名・カラーバー・テーブル名構成）、およびオブジェクトツリー／テーブル一覧のカラーフィルタを実装。
- **カラーテーマ拡張（全10種類）とマニュアル刷新**:
  - ライト / ダーク / セピア / ブループリント / パステル（spring, summer, autumn, winter） / モノクロ / ユニバーサル（CUD）の全10テーマを整備し、操作マニュアルを全11章構成へ全面刷新。

## [v1.2.5] - 2026-08-29

### 🔧 修正・改善 (Bug Fixes & Enhancements)
- **DBMLパース時の logicalName 上書き不具合修正**: テーブルのカラム定義で `logicalName` が消滅していた不具合を修正。
- **空テーブル定義の安全パース対応**: カラムが0件の空テーブルを表示できるよう改善。
- **Oracle SQL インポート時の tablespace 等カスタム属性出力漏れの修復**: SQL インポート時に抽出された `tablespace`, `index_tablespace`, `lob_tablespace`, `logging` が DBML 生成時に除外されていた問題を修正。
- **コンソールログのクリーンアップ**: SQL インポート時やパース時における巨大な DBML テキスト出力を抑制し、視認性とパフォーマンスを向上。

## [v1.2.4] - 2026-08-24

### 🔧 修正・改善 (Bug Fixes & Enhancements)
- **SQL DDL エクスポート時の引用符および文字エンコーディング修復**: DDL エクスポート時に HTML エンティティ変換される不具合を修正。

- **テーブル名アルファベット昇順（A-Z）自動ソート統一**: マイグレーション比較時のテーブル位置ズレを低減。
