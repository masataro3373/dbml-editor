# 05. ER図（実体関連図）の作成と操作

## 1. ER図ビューの特徴
DBML Editor の ER図（Entity-Relationship Diagram）機能では、1つのプロジェクト内に **複数の ER図** を作成し、用途別（全体俯瞰図、業務ドメイン別詳細図、テーブル抜粋図など）にレイアウトを保存できます。

さらに **マルチスキーマ（クロススキーマ）配置** に対応しており、異なるスキーマに属するテーブル同士を 1 枚の ER図キャンバス上に並べて関連を可視化できます。

---

## 2. ER図の作成とテーブル配置

1. **ER図の新規作成**:
   左ペイン（オブジェクトツリー）の「ER図」見出し横にある **「＋」ボタン** をクリックし、ER図の名前（例: `全体ER図`, `動静管理サブシステム`）を入力して作成します。
2. **キャンバスへのテーブル追加・除外**:
   - ER図ツールバーの **「テーブル選択 / 追加」** から、キャンバスに表示したいスキーマおよびテーブルにチェックを入れて追加します。
   - キャンバス上のテーブルカードから個別に表示を除外することも可能です（ER図から除外しても、スキーマ上のテーブル定義自体は削除されません）。
3. **テーブルカードの移動と自動整列**:
   - 各テーブルカードをドラッグ＆ドロップして自由な位置へ配置できます。座標は自動的に保存されます。
   - ツールバーの **「自動整列」** を実行すると、テーブル間のリレーション構造を考慮して重なりのない見やすい配置へ一括整列できます。

---

## 3. テーブルカードとリレーションの表示仕様

### テーブルカードの表示要素
- **ヘッダ構造**:
  各テーブルカードのヘッダには **「スキーマ名」＋「ヘッダカラーバー（テーブルに設定した色）」＋「テーブル名」** が明瞭に表示されます。
- **表示モード切替（ツールバー）**:
  - **物理名 / 論理名 / 両方表示**: テーブル名およびカラム名を「物理名のみ」「論理名のみ」「物理名＋論理名併記」にワンクリックで切り替えられます。
  - **カラム表示範囲**: 「全カラム表示」「主キー（PK）・外部キー（FK）のみ表示」「テーブル名のみ（コンパクト表示）」を切り替えられます。

### リレーション線（Crow's foot 記法）
- テーブル間に定義された外部キー（`Ref`）に基づき、親テーブルと子テーブルを結ぶリレーション線が自動描画されます。
- 多重度（1対多、1対1、多対多）が直感的な **カラスの足（Crow's foot）記法** で表現され、テーブルカードをドラッグ移動すると接続エッジが自動的に最適位置へ追従します。

---

## 4. キャンバス装飾（メモ付箋・グループ枠・図面スタンプ）

ER図を設計レビュー資料としてそのまま活用できるよう、キャンバス上に以下の補助オブジェクトを配置できます。

| 機能 | 説明 |
| :--- | :--- |
| **メモ付箋 (Memo)** | キャンバス上の任意の位置にテキスト付箋を貼り付け、設計上の注意点や補足説明を記入できます（色・サイズ変更可） |
| **グループ枠 (Box)** | 関連する複数のテーブルを囲む背景ボックス（境界枠＋見出しラベル）を配置し、サブシステムや業務領域のまとまりを視覚化できます |
| **図面情報スタンプ** | 図面の隅に「図面タイトル・説明・作成情報」などのスタンプを表示し、クリックして内容を編集できます |

---

## 5. ズーム・ミニマップ・画像出力（PNG / SVG）

- **ズーム & パン移動**:
  - マウスホイールで拡大・縮小、キャンバスの空白領域をドラッグしてパン（視点移動）が行えます。
  - ツールバーの「全体フィット（画面内に収める）」「100% リセット」ボタンで素早く視点を戻せます。
- **ミニマップ**:
  - キャンバス右下のミニマップで全体構造と現在の表示領域を確認でき、ミニマップ上のクリック／ドラッグで高速に視点ジャンプできます。
- **画像エクスポート（PNG / SVG）**:
  - ツールバーの画像出力ボタンから、現在の ER図（テーブルのヘッダカラー、スキーマ名、リレーション線、メモ付箋、グループ枠を含む）を高解像度の **PNG 画像** または拡大しても劣化しない **SVG ベクター画像** として即座にダウンロードできます。
- **ER図 JSON の入出力**:
  - 配置座標やメモ・枠の情報は「📁 ファイル」→「エクスポート...」→「ER図 (JSON)」で単体ファイルとしても書き出し・復元でき、プロジェクト全体の ZIP エクスポートにもすべて同梱されます。
