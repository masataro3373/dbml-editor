# 07. エクスポート & HTML仕様書出力

## 1. エクスポートダイアログの起動
ヘッダーの **「📁 ファイル」→「📤 エクスポート...」** をクリックすると、エクスポートモーダルが開きます。設計中のプロジェクトやスキーマを、用途に合わせて以下のフォーマットで出力できます。

---

## 2. 対応エクスポート形式一覧

| 出力フォーマット | 用途・特徴 |
| :--- | :--- |
| **プロジェクト (ZIP)** | 全スキーマ（`.dbml`）、全 ER図（`.json`）、プロジェクト設定（`project.json`）を1つの ZIP アーカイブに一括保存（バックアップ・環境移行用） |
| **スキーマ (DBML)** | 選択したスキーマを正規化済みの `.dbml` テキストファイルとして出力 |
| **SQL (DDL)** | 対象 DBMS 方言に応じた `CREATE TABLE` / `ALTER TABLE` / `CREATE INDEX` / `COMMENT ON` / `DROP TABLE` スクリプトを生成 |
| **HTML 仕様書** | 単一 HTML ファイル完結型のインタラクティブな Web データベース仕様書（**標準版：カード形式** ／ **検索強化版：カラムグリッド形式**）を出力 |
| **Java コード** | テーブル定義から Java クラス（Entity / Model または Value Object `Vo`）のソースコードを生成 |
| **CSV** | 選択スキーマ内の全テーブル・カラム定義一覧を CSV ファイル（Excel 閲覧対応）として出力 |
| **ER図 (JSON)** | 選択した ER図のレイアウト座標・メモ付箋・グループ枠定義を JSON ファイルとして出力 |

---

## 3. SQL (DDL) エクスポートの詳細オプション

「SQL (DDL)」タブでは、スキーマの DBMS 方言（または任意に選択した方言プラグイン）に基づいた高精度な DDL を生成・プレビュー・ダウンロードできます。

- **対象スキーマ & DBMS 方言**:
  出力対象のスキーマと DDL 方言（Oracle、PostgreSQL、MySQL、SQL Server、Cloud Spanner、Snowflake、BigQuery、Redshift、Databricks 等）を選択します。
- **DDL 生成オプション**:
  - **DROP TABLE 文の出力**: `出力しない` / `各 CREATE TABLE の直前に出力` / `ファイル先頭にまとめて出力` から選択できます。
  - **COMMENT 文の出力**: テーブル論理名・カラム論理名や Note を `COMMENT ON TABLE / COLUMN`（または DBMS 固有コメント構文）として出力します。
  - **物理属性・表領域の出力**: Oracle 等の物理メタデータ（`TABLESPACE`, `PCTFREE`, `INITRANS`, `STORAGE`, `LOGGING`, `LOB STORE AS`、`USING INDEX TABLESPACE` 等）を DDL に含めるかを制御できます。
- **文字コード & 改行コード**:
  - **文字コード**: `UTF-8` または `Shift_JIS`（Windows / レガシー環境向け）
  - **改行コード**: `LF (\n)` または `CRLF (\r\n)`
- **出力対象テーブルの選択 & 分割方式**:
  - スキーマ内の全テーブルを **1つの `.sql` ファイルに結合出力** するか、**テーブルごとの個別 `.sql` ファイルをまとめた `.zip` で一括ダウンロード** するかを切り替えられます。
  - チェックボックスで特定のテーブルのみに絞って DDL を出力することも可能です。

## 4. HTML 仕様書出力（2つのレイアウト形式 & 日英リアルタイム切替）

「HTML 仕様書」タブでは、外部ライブラリやインターネット接続を一切必要としない **単一 `.html` ファイル完結型の Web 仕様書** を出力できます。

### 2種類の出力フォーマット
用途に合わせて以下の 2 形式から選択して出力できます。

1. **標準版（テーブルカード形式）**:
   - 左サイドバーにスキーマ・テーブル目次を備え、メイン画面に各テーブルの詳細仕様カード（テーブル基本情報、物理属性、カラム定義一覧、インデックス一覧、外部キー一覧、Check制約一覧）を見やすく並べる王道のテーブル定義書フォーマットです。
2. **検索強化版（カラムグリッド形式）**:
   - プロジェクト内の全テーブル・全カラムを 1 つの高速データグリッドに展開し、**「スキーマ名」「テーブル物理名／論理名」「カラム物理名／論理名」「データ型」「PK / FK / NOT NULL」「備考」** などの条件で横断的にリアルタイム検索・フィルタリングできるデータディクショナリ型フォーマットです。
   - 「共通カラムがどのテーブルに使われているか」「特定の型・桁数のカラムがどこにあるか」を瞬時に調査できます。

### HTML 仕様書の共通機能
- **日本語 / 英語（JA / EN）リアルタイム表示切替**:
  出力された HTML ファイル内に日英両方の見出し・UI辞書が埋め込まれており、閲覧者は仕様書画面右上の **言語切替ボタン（`JA / EN`）** でいつでも日本語表示と英語表示を切り替えられます（出力時の初期表示言語もエクスポート画面で指定可能）。
- **全10種類のカラーテーマ内蔵**:
  DBML Editor 本体と同じ全 10 種類のテーマ（ライト、ダーク、セピア、ブループリント、パステル4種、モノクロ、ユニバーサル）を閲覧者がプルダウンで自由に切り替えられます。
- **SharePoint / Teams やローカルでの手軽な共有**:
  CSS・スクリプト・データがすべて 1 ファイルに収まっているため、メール添付やファイルサーバー配置はもちろん、SharePoint ドキュメントライブラリに配置して Microsoft Teams のタブから直接アプリのように閲覧・検索する用途にも最適です。
