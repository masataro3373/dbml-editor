# 04. テーブルグループ & ノート機能

## 1. テーブルグループ (TableGroup)

テーブル数が数十〜数百件に及ぶ大規模スキーマでは、業務ドメインやサブシステム単位（例: `マスタ系`, `受注・動静トラン`, `権限・システム管理` など）で **テーブルグループ（TableGroup）** を作成して整理できます。

### テーブルグループの作成と編集（デュアルリスト操作）
1. 左ペイン（オブジェクトツリー）の「テーブルグループ」見出し横にある **「＋」ボタン** をクリックするか、既存のグループ名をクリックします。
2. テーブルグループ編集画面が開きます。
   - **グループ名**: グループの識別名（例: `マスタ管理`）を入力します。
   - **所属テーブルの選択（デュアルリスト UI）**:
     - 左側の **「未所属テーブル」** リストと、右側の **「所属テーブル」** リストが並んで表示されます。
     - 検索ボックスでテーブル名を絞り込みながら、テーブルを選択して中央の移動ボタン（`▶ 追加` / `◀ 解除`）をクリックするだけで、直感的にグループ編成を行えます。
   - **ノート (Note)**: グループの目的や対象サブシステムの説明メモを記述できます。
3. **「保存」** をクリックすると、DBML の `TableGroup "グループ名" { ... }` として即座に反映・自動保存されます。

### オブジェクトツリーの「グループ化表示」と「テーブル名順」の切り替え
左ペインの「テーブル」見出し右側にある **表示オプション（`⋮` / ソート切替メニュー）** から、ツリー上のテーブル表示方法をいつでも切り替えられます。

- **グループ化表示**:
  作成したテーブルグループごとにフォルダ分けしてテーブルを表示します（どのグループにも属していないテーブルは「未分類」にまとまります）。
- **テーブル名順**:
  グループ分けを行わず、スキーマ内の全テーブルをアルファベット昇順（A-Z）でフラットに一覧表示します。

---

## 2. ノート機能 (Note / 設計メモ)

テーブルやカラム個別の備考（Note）とは別に、スキーマ全体に関わる設計方針、命名規約、バッチ連携仕様、課題メモなどを独立して記録できる **ノート（Sticky Note）** 機能を備えています。

### ノートの作成・閲覧・編集
1. **新規作成**:
   左ペイン（オブジェクトツリー）の「ノート」見出し横にある **「＋」ボタン** をクリックします。
2. **編集**:
   - **ノート名（識別名）**: ノートのタイトル／ID（例: `共通カラム規約`, `表領域設計メモ`）を入力します。
   - **本文**: 設計メモや仕様を複数行テキストで自由に記述し、**「保存」** をクリックします。
3. **参照と削除**:
   - 左ツリーの「ノート」配下からノート名をクリックすると、メインワークスペースにノート参照ビューが表示され、「編集」ボタンからいつでも内容を更新できます。
   - 不要になったノートはツリーまたはノート画面の「🗑️ 削除」ボタンから削除できます。

> 作成したノートは DBML 標準の `Note "ノート名" { '''...''' }` 構文としてスキーマ内に保存され、プロジェクトのエクスポート時にも設計資産としてそのまま保持されます。
